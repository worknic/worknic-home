# WORKNIC 사업자 주문

사업자 회원가입 → 담당자 승인 → 장바구니 → 주문·거래명세서 자동 생성 → 계좌이체 → 워크닉 입금 확인 → 배송 준비 → 운송장 등록.

현재 공식 홈페이지는 GitHub Pages 정적 호스팅입니다. 이 서버를 GitHub Pages에 올리는 것만으로 회원가입·주문 저장이 동작하지 않습니다. Node.js 24와 영속 디스크가 있는 별도 서버 및 HTTPS 연결이 필요합니다. 이 변경은 운영 중인 `/business/` 가입 신청과 기존 브랜드 관리 기능을 변경하지 않습니다. 아직 공식 홈페이지 메뉴에서 주문 페이지로 연결하지 않았습니다.

## 반영한 운영 기준

- 하나은행 / 556-910020-91004 / 워크닉 주식회사.
- 부가세 포함 상품금액 **500,000원 이상 무료배송**, 미만 **배송·포장비 5,000원**.
- 명세서에는 상품금액, 배송·포장비, 공급가액, 부가세, 합계 입금액을 구분합니다.
- 사업자번호 체크섬은 입력 검증이며, 실제 사업자 확인은 담당자가 진행합니다. 승인 전에는 가격·주문 기능을 제공하지 않습니다.
- 입금 확인은 은행 자동 연동 없이 담당자가 실제 입금내역과 금액을 확인해 처리합니다.
- 제주·도서산간, 대형·중량 상품은 별도 배송비 확인 대상입니다. 상품의 `배송비 별도 확인`을 선택하면 직접 주문을 막습니다. 운영자가 확인해 일반 배송이 가능한 주문으로 안내해야 합니다.
- 입금기한은 초기값 3일이며 관리 화면에서 1~14일로 변경할 수 있습니다. 기한이 지난 미입금 주문은 만료되고 예약 수량이 복원됩니다. 기한 후 입금은 담당자가 직접 확인해 재주문·환불 등을 안내합니다.
- 거래명세서는 세금계산서·결제 영수증과 별개입니다. 전자세금계산서 자동 발행과 카드결제는 포함하지 않습니다.

## 로컬 실행

외부 패키지 설치 없이 Node.js 24 이상을 사용합니다.

```sh
cd trade
npm run admin
npm start
```

`http://localhost:8080/trade/` 고객 화면, `http://localhost:8080/trade/admin` 담당자 화면입니다. 초기 주문 접수는 닫혀 있고 모든 상품의 단가·수량은 미설정입니다. 관리자 생성 명령에 비밀번호를 인수로 넣지 마세요. 대화식 입력은 화면에 표시되지 않습니다. 기존 OS 관리자 계정과 자동으로 연결되지 않으며, 이 서비스의 담당자 계정을 별도로 생성합니다.

관리자는 운영 설정에서 계좌·배송비를 확인하고, 상품별 단가·수량을 설정한 후 주문 접수를 엽니다. 고객은 가입 신청 후 로그인해 승인 대기를 확인할 수 있습니다.

```sh
npm test
```

테스트는 임시 SQLite 파일을 사용하고 정리합니다. 실제 회원, 주문, 은행에 접근하지 않습니다. 브라우저 검증용 서버는 `node tests/browser-server.mjs`이며, 검증 전용 상품·계정만 사용합니다. 운영에서 실행하지 마세요.

검증 서버 실행 후 Python Playwright·Chromium이 있는 환경에서 `python tests/browser-flow.py`로 가입부터 발송까지 확인할 수 있습니다. 화면 캡처·샘플 PDF는 기본 `/tmp/worknic-trade-qa`에 저장합니다.
