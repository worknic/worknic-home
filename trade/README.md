# WORKNIC 사업자 견적·픽업 베타

기존 공식 홈페이지·상품 원본과 OS 업무 도구를 유지하는 별도 서비스입니다. PR #3의 주문 초안을 기반으로 확장했으며 해당 PR과 운영 main은 변경하지 않습니다.

현재는 **로컬 기능 검증 완료, 운영 미배포** 상태입니다. 고객용 화면은 `/trade/`, 관리 화면은 `/trade/admin`입니다. 운영에서는 OS의 `trade-manager/` 메뉴를 통해 관리 세션을 연결합니다.

## 구현 범위

- 판매가 XLSX 내려받기 → 검증 미리보기 → 원자적 일괄 적용 → 충돌 없는 적용 내역 복원. 상품번호·옵션번호를 원본 키로 사용합니다.
- 판매가 미정은 빈 값으로 유지합니다. 공개 상품 카탈로그에는 가격을 추가하지 않습니다.
- 기존 OS 사업자 승인정보와 실제 담당자를 대조하고 일회용 계정 확인 링크를 발급합니다. 계정 활성화 후에도 거래 API 요청마다 OS 승인상태를 다시 확인합니다.
- 공개 상품 탐색 → 승인 회원 견적 요청 → 담당자 견적 발행 → 고객 수락 → 고정 금액 주문·명세서 → 실제 입금 확인 → 픽업 준비 → 개별 코드 열람 → 고객 수령 표시 → 담당자 실물 확인·잠금장치 코드 폐기.
- 옵션별 수량을 분리합니다. 입금기한 만료 시 예약했던 수량을 한 번만 복원합니다.
- 개별 수령코드는 서버에서 AES-256-GCM으로 암호화합니다. 다른 회원에게 보이지 않으며 시간 밖 접근을 차단합니다. 화면에서는 30초 뒤 또는 화면을 벗어날 때 숨깁니다.
- 홈 화면 추가용 PWA manifest·서비스워커를 제공합니다. API·회원·주문·명세서·수령코드는 오프라인 캐시에 저장하지 않습니다. 실제 휴대폰 설치는 운영 HTTPS 배포 후 검증해야 합니다.

## 확인된 운영 정보

진접 픽업은 사용자 제공 기준 **진접중학교 앞 / 오후 7시~11시**입니다. 운영 요일은 미확인입니다. 포천 영업시간 외 수령은 개별 비밀번호 방식입니다. 장소별 접수는 기본적으로 닫혀 있습니다.

은행은 하나은행 / 워크닉 주식회사 / 556-910020-91004입니다. 자동 입금 확인·카드결제·보관함 원격 개방·자동 알림 발송은 구현 범위가 아닙니다. 실제 잠금장치 코드는 담당자가 현장에서 설정하고 변경합니다.

배송은 기존 초안 코드에 남아 있지만 베타에서는 레거시 직접 주문 API를 차단합니다. 배송비 50만원 미만 5천원·이상 무료 방침은 보존하되, 포장비·부가세 및 최종 문서 양식은 확인 전 운영을 열지 않습니다. 이번 베타 견적은 상품별 부가세 기준과 별도 확정한 픽업 비용을 사용합니다.

## 개발 검증

Node.js 24 이상:

```sh
cd trade
npm ci
npm test
node tests/beta-browser-server.mjs
```

로컬 fixture는 `http://localhost:8086/trade/`이며 실제 OS·주문에 쓰지 않는 임시 DB를 사용합니다. 검증용 계정과 가격은 fixture 소스에만 있습니다. 운영 실행은 `NODE_ENV=production`과 모든 비밀 설정·영속 볼륨이 필요합니다.

운영 연결은 [DEPLOYMENT.md](docs/DEPLOYMENT.md), 담당자 사용 순서는 [OPERATIONS.md](docs/OPERATIONS.md)를 확인하세요.
