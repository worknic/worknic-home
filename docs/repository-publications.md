# 검증 상품 묶음 공개

2026-11-21부터 검수된 상품의 홈페이지 일괄 공개는 `data/published-content.json`으로도 배포한다. 기존 OS 발행 52개는 이 파일로 복제하지 않는다. 이번 OLFA 29개는 OS 공개 조회에서 기존 발행본이 없는 것을 확인한 후 저장소 관리 대상으로 지정했다.

- 상품코드/품명은 원본 39,797개 목록과 정확히 대조한다. 원본 JSON, 가격, 재고, 상품명, 브랜드 ID는 수정하지 않는다.
- 모델별 공식 문서·사진을 확인하고 4개 검수 항목이 모두 true인 발행본만 포함한다.
- 각 레코드의 `publicationChannel: repository`는 관리 주체를 명시한다. 이 코드들은 홈페이지 저장소에서 수정/비공개 처리한다. OS 관리자 화면 및 OS 이력에 동기화됐다는 뜻이 아니다.
- 비공개 시 항목을 지우는 대신 `withdrawn: true`로 배포한다. 이 코드는 OS에 동일 코드가 있더라도 표시하지 않는다.
- OS로 관리 주체를 이전할 때는 먼저 동일 내용의 검수본을 OS에서 발행하고 공개 조회를 대조한 다음 저장소 항목을 제거한다. 이후 OS의 발행 해제 기능이 적용된다.
- 기존 OS 관리 코드는 기존 공개 API만 사용한다. 저장소 조회 실패가 OS 상품을 숨기지 않으며, 저장소 발행본에 OS의 비공개/초안 값을 섞지 않는다.
- 공개 경로: 취급 목록 검색 → 상품코드 상세, `/parts/` 모델별 사진 카드. 제품별 서로 다른 사진을 하나의 대표 사진으로 묶지 않는다.

검증: `node --test scripts/product-content-tests.mjs scripts/repository-content-tests.mjs`.
사진은 흰 배경 1000×1000, 공식 원본 보존. 공개 후 원격 JSON·이미지 바이트와 실제 화면을 확인한다.
