# 사업자 가격 관리와 거래 안내

공개 페이지에서는 제품 설명·규격을 제공하며 가격을 표시하지 않는다. 사업자 정보 확인·워크닉 승인 후 담당자가 견적서로 가격과 공급 조건을 안내하고, 거래 확정 후 거래명세서를 전달한다. 이 문구는 담당자 안내 절차이며 자동 문서 발송이나 온라인 주문 기능의 구현 완료를 뜻하지 않는다. 사업자 주문 초안 PR #3과 분리해 운영한다.

## 판매가 엑셀 일괄 관리 후속 구현안

현재 CSV 가져오기는 스마트스토어 상품목록의 비공개 등록용이다. 판매가 일괄 수정 기능이 아니다. 후속 기능은 WORKNIC OS의 관리자 전용 가격 관리 메뉴로 추가한다.

- `.xlsx` 업로드, 변경 미리보기, 오류 행 제외, 관리자 적용, 변경 이력 및 이전 가격 복원 순서로 처리한다.
- 상품 ID + 옵션 ID를 갱신 키로 사용한다. 모델명이나 상품명만으로 매칭하지 않는다. 옵션 없는 상품과 다중 옵션 상품을 구분한다.
- 필수 항목: 상품 ID, 옵션 ID(옵션 없는 상품은 단품으로 명시), 거래 판매가, 부가세 기준, 적용일. 브랜드·상품명·모델·판매 단위는 대조용으로 제공한다.
- 미등록 ID, 중복 키, 알 수 없는 옵션, 음수·잘못된 숫자, 부가세 기준 또는 단위 미확인 행은 저장 전에 차단한다. 빈칸을 0원으로 바꾸지 않는다.
- 가격 미정은 별도 문의 상태로 구분한다. 미정 상품을 임의 가격으로 채우지 않는다.
- 판매가는 공개 상품 JSON, 정적 파일, 비로그인 응답에 넣지 않고 별도 비공개 가격 원본에 보관한다. 견적 단가는 승인된 사업자와 관리자 권한을 서버에서 확인한 뒤 사용한다.
- 견적서에는 발행 시점의 단가·수량·부가세 기준을 저장한다. 이후 엑셀로 가격을 변경해도 이미 발행한 문서의 금액을 바꾸지 않는다.
- 문서 수신처·전달 방법, 부가세와 판매 단위, 거래명세서 양식은 운영 기준을 확인한 뒤 적용한다. 자동 발송 완료로 안내하지 않는다.

이 문서는 후속 구현 기준이며 엑셀 판매가 업로드·비공개 가격 저장·자동 문서 발송 기능은 아직 배포되지 않았다.
