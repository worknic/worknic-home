# 상품 표현 기준

기존 예시·테스트 상품을 포함한 모든 공개 상품과 신규 초안에 같은 기준을 적용한다.

- 목록과 상세 대표 사진: 1:1 연그레이 영역, 원본 전체 표시, 색상 필터·왜곡·크롭 금지.
- 사진 파일 자체의 배경 통일과 화면의 연그레이 프레임 적용은 서로 다른 검수 항목이다. 프레임 적용만으로 썸네일 제작 완료로 표시하지 않는다.
- 해상도가 부족하면 원본 교체 대상으로 유지한다. 단순 확대를 고해상도 교체로 취급하지 않는다.
- 상세는 확인된 설명·규격, 판매 단위와 구성, 구매 전 확인, WORKNIC'S NOTE, 출처와 확인일을 공통 양식으로 보여준다.
- guide.configuration의 unit, quantity, included, excluded, options는 확인된 값만 기록한다. 빈 항목을 추정해 채우지 않는다.
- 제조사 사용 사진은 해당 모델·출처·해상도가 확인된 경우만 표시한다. 검증된 사용 사진이 없으면 생략한다.
- 실제 출처·모델·확인일이 검증된 소비자 의견만 표시한다. 검증된 후기가 없으면 생략한다.
- 구글 시트 OS_브랜드상품의 기존 guide와 원본 필드를 보존한다. 화면 표현 변경을 이유로 상품 revision이나 확인일을 갱신하지 않는다.
- 신규 상품은 원본 대조와 상품별 검토가 끝나기 전 비공개로 준비한다.
- 페스툴의 시스테이너는 브랜드 내부의 별도 탐색 분류로 제공한다. 공구와 함께 전체 목록에서도 동일한 상품 원본을 사용한다.
- 동일 제조사 상품코드와 판매 원본을 확인한 색상별 상품은 옵션으로 연결한다. 이름이나 비슷한 사진만으로 서로 다른 모델을 합치지 않는다.
- CSV 추출 시 브랜드 미확인·미등록 상품과 분류 불명확 상품은 후보에서 제외한다. 브랜드의 취급 제품군을 상품 카테고리로 일괄 복사하지 않는다.
- 베어링 / 오링·기계용 씰 / 볼트·너트·와셔 / V벨트·동력 전달 벨트는 공장소모품의 하위 분류로 관리한다.
- 에어피팅·튜브 연결 / 에어카플러 / 에어실린더 / 솔레노이드밸브·공압 제어 밸브는 유공압·에어기계부속의 하위 분류로 관리한다. 압력·나사산·구경·사용 유체·작동 방식·코일 전압은 확인된 내용만 기록한다.
- 부품과 해당 부품용 공구를 구분한다. 베어링 풀러와 볼트커터를 부품으로 분류하지 않는다. 여러 하위 분류가 충돌하면 자동 가져오기에서 제외한다.
- 배터리·충전기는 전동공구 본체와 별도 하위 분류로 관리한다. 명확히 확인되는 기계 교체 부품은 공장소모품의 기계 부속·교체 부품으로 분류한다. 드릴비트는 드릴 본체와 구분한다.
- 판매자센터 화면에서 추출한 목록은 상품번호·상품명·판매·전시 상태의 원본으로만 취급한다. 목록에서 확보하지 못한 사진·사양·호환성은 채우지 않고 비공개 검수 대기로 유지한다. 타사의 마끼다 호환 제품을 마끼다 브랜드 상품으로 등록하지 않는다.
